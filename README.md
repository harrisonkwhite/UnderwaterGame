*Underwater Game* was a discontinued game project originally intended to be the second major project (after *MANIC*) by Geta Games Team, an online game development team I ran in my free time after school between 2015 and 2021. The project entered development towards the end of 2019 and was cancelled in early 2021 largely due to poor project management and design direction on my part. All of this game's code was written by me, though in retrospect I wish I had put more effort into finding other people to actively contribute to the coding, so more of my attention could have been put towards design.

This game was written in C# using the XNA / MonoGame Framework, which I was inspired to use after hearing that games like *Celeste* and *Stardew Valley* were made with it. I no longer use it however, as I've shifted more towards low-level styles of programming.

You can play what ultimately became of this game here: https://getagamesteam.itch.io/underwater-game
